## Convention

```markdown
# ADR NNNN — Title

| Field | Value |
|-------|-------|
| Status | Proposed \| Accepted \| Implemented \| Superseded \| Deprecated |
| Date | YYYY-MM-DD |
| Type | Decision | Implementation plan | Checklist | Runbook |
```

Do not reuse numbers. Supersede with a new ADR when replacing a decision.
